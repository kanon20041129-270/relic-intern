# 4分ピッチ台本 v2｜AnswerLoop

進行目安は3分40秒。残り20秒は操作や切り替えの予備。括弧内の操作指示は読み上げない。

### 【1 COVER｜20秒】
Baseconnectの長期インターンで、リリース直後のプロダクトの問い合わせ対応を担当していました。同じような質問のたびに資料を探して返信を書く。それだけで一日の大半が終わっていました。

### 【2 PROBLEM｜18秒】
ナレッジを約80件整えると、私の対応時間は概算で一日約8時間から15分未満に。兼務の担当者に、プロダクトを改善する時間を戻したいと思いました。

### 【3 TARGET｜21秒】
最初は従業員数十名の自社SaaS企業です。使うのは問い合わせを兼務する事業担当者、買うのは事業責任者。次は大企業のCS・コールセンター責任者と、定型電話の一窓口で試し、解決率・応答時間・再問い合わせを測ります。

### 【4 PRODUCT｜24秒】
（横動画を再生。話しながら15秒のカットを一度だけ流す）
AnswerLoopは、送信前に根拠つきの答えを出します。承認済みの回答に一致したときだけ表示します。メール・フォーム・チャット・電話を一つの受信箱にまとめ、人が確認した答えを次の問い合わせに活かします。

### 【5 DEMO｜47秒】
（「追加料金はいつ発生しますか？」と入力し、変換を確定）追加料金の質問を打つと、送信前に日割りの答えと根拠が出ます。
（模擬通話を再生）電話でも同じナレッジを使い、答えられる質問にはその場で答えます。
（要確認を開く）請求書払いは資料が食い違うので、質問と確認先を要約して人に渡します。
（追記候補の差分を開き、承認）同じ質問14件から料金ページの追記案を出し、人が確認して承認します。

### 【6 COMPETITION｜17秒】
国内外のツールを4つの類型で比較しました。送信前に根拠つきで即答し、ページ改善後に同じ問い合わせが減ったかまで測る例は、公開情報では確認できませんでした。

### 【7 BUSINESS｜21秒】
価格仮説は、30日19,800円で試して、Starterは月9,800円。電話は月29,800円のPro、既存窓口との接続は年額見積もりです。月60件で1件8分短縮なら、月8時間、約24,000円相当です。

### 【8 SNS｜17秒】
（縦動画は再生せず、画面を示す）
TikTokの初投稿は15秒、あるあるを一操作で見せます。音を拍に合わせ、質問を替えて10本。冒頭の維持率、平均視聴秒数、業務コメントやデモ希望を見ます。

### 【9 FEEDBACK｜22秒】
事前の指摘で対象を兼務のSaaS担当者に絞りました。当日、送信後の待ち時間、電話対応、大企業への展開を指摘され、送信前の即答と模擬通話を加え、大企業向けを含む三段階の料金とトライアルに変えました。

### 【10 NEXT｜13秒】
まず5社で、3か月目の継続と実際の返信に使われた回答案の件数を見ます。問い合わせを、返すものから、減らすものへ。ありがとうございました。
