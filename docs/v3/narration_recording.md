# ナレーション録音の手順（ChatGPTの読み上げ）

## 手順（iPhoneが一番確実）
1. iPhoneのChatGPTアプリで、下の「15秒用」をそのまま送る（返答はそのまま繰り返してもらう）。
2. 返ってきたメッセージを長押し →「読み上げる」。声はChatGPTの設定（設定 → 音声）で選べる。落ち着いた声がおすすめ。
3. 読み上げの前に、コントロールセンターから「画面収録」を開始し、読み上げが終わったら停止する（アプリの音も一緒に録音される）。
4. 30秒用も同じように録る。
5. 2本の動画をAirDropでMacに送り、`relic-inquiry-pitch/video/assets/narration/rec/` に `15.mp4`・`30.mp4` の名前で置く（フォルダは作成済み）。
6. 私に「置いた」と伝える → 無音で文ごとに切り分け、動画のタイミングに合わせて差し替え、書き出し直す。

## ChatGPTに送る文（15秒用）
```
次の文章を、そのまま一字一句変えずに返してください。読み上げ用です。

また、同じ料金の質問。

送信する前に、もう答えが出てる。

根拠を見て、承認するだけ。

よく来る質問は、ページに追記。

デモは、プロフィールから。
```

## ChatGPTに送る文（30秒用）
```
次の文章を、そのまま一字一句変えずに返してください。読み上げ用です。

また、同じ料金の質問。前の返信、どこだっけ。

アンサーループなら、送信する前に、根拠つきで答えが出ます。

資料が食い違えば、AIは答えず、人へ。

電話でも、同じ根拠で、その場で答えます。

よく来る質問は、ページに追記して、根本から減らす。

デモは、プロフィールから。
```

## 注意
- 文と文の間に少し間が空くほど、切り分けが正確になる。
- 読み上げが速すぎて枠に収まらない文は、私の側で最大1.1倍まで調整する。それ以上なら画面側の尺を変える。
- ChatGPTの音声の商用利用条件は、投稿前にOpenAIの利用規約で確認する（未確認）。
