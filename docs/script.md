# 4分ピッチ台本｜AnswerLoop（仮称）

### 【1 表紙】0:00–0:20｜原体験
Baseconnectの長期インターンで、リリース直後のプロダクトの問い合わせ対応を担当していました。同じような質問のたびに資料を探して返信を書く。それだけで一日の大半が終わっていました。

### 【2 課題】0:20–0:40｜解決したい課題
少人数で自社サービスを運営する会社では、事業担当者が問い合わせ窓口を兼務しています。返信を優先するほど、プロダクト改善やマーケティングの時間が削られる。これが解決したい課題です。

### 【3 ターゲット】0:40–0:58｜ターゲット
最初のお客さまは、自社SaaSをリリースした従業員数十名のスタートアップです。使うのは問い合わせを兼務する事業担当者、お金を出すのは事業責任者。今ある資料で答えられる質問が繰り返し届く会社です。

### 【4 プロダクト → 横動画を再生】0:58–1:15｜作ったプロダクト
作ったのは「AnswerLoop」です。FAQや仕様資料を根拠に回答案をつくり、担当者が確認して返信するツールです。（動画 約15秒を流す。または話しながら再生）

### 【5 デモ】1:15–1:55｜デモ
実際の画面です。「追加料金はいつ発生しますか」という質問には、料金ページと規約の該当箇所を根拠に示した回答案が出ます。担当者は根拠を確かめて、承認するだけです。
一方、「請求書払いはできますか」は、料金ページと社内資料で記載が食い違っているので、AIは答えずに「要確認」として人に回します。私が実際につまずいた問題です。
最後に、頻出の質問から料金ページへの追記候補を出します。返信を速くするだけでなく、問い合わせそのものを減らします。

### 【6 マネタイズ】1:55–2:30｜収益化
収益は、30日間の有償トライアル1万9,800円と、継続の月額9,800円です。トライアルでは導入前後の対応時間を測ります。たとえば月60件で1件8分短くなれば、月8時間。時給3,000円で換算すると月2万4,000円分の時間が戻るので、月額9,800円は回収できます。個別のFAQ整理は別料金にし、支援工数で赤字にしません。

### 【7 SNS → 縦動画を再生】2:30–2:52｜SNSマーケティング
SNSはTikTokとXで、30秒の動画を出します。最初の1秒で「また同じ料金の質問。前の返信どこだっけ？」というあるあるを見せ、解決までを一気に見せます。狙いは再生数ではなく、試験導入の相談件数です。

### 【8 フィードバック】2:52–3:32｜事前FBを受けた変更
事前のフィードバックを受けて、2つ変えました。
1つ目は対象です。「AI専任者のいない中小企業」全般から、事業担当者が問い合わせを兼務する自社SaaS企業に絞りました。競合との差と、他社での再現性を出すためです。
2つ目は売り方です。初期10万円と月3万円から、有償トライアルと月9,800円に変え、個別の支援は別料金にしました。支援工数を抑え、どの会社にも同じ形で入れるためです。
指標には、ページ改善後に同じ問い合わせが減ったかも加えました。残る課題は、回答の精度と、3か月目も使い続けてもらえるかです。

### 【9 展望】3:32–3:50｜これから
まず5社に試してもらい、3か月目の継続と、実際の返信に使われた回答案の件数で判断します。問い合わせを、返すものから、減らすものへ変えていきます。

### 【9 のまま】3:50–4:00｜感想
作るだけでなく、誰に届けてどう広げるかまで一日で考えきれたのが一番の学びでした。ありがとうございました。
