# AnswerLoop｜TikTokの投稿設計と音響リサーチ

**出典確認日：2026-11-28（本文中の全Web出典に共通）**  
対象は日本語圏の新規アカウント（0フォロワー）、広告費なし。商材・デモデータは [AnswerLoop共通仕様書](../SPEC.md) に準拠。各節の「確認できたこと」は出典に基づき、「検証案」「制作案」はAnswerLoop向けの仮説・初期設定を示す。

## 1. 0フォロワーからの初速

### 確認できたこと

TikTokは、For Youの配信候補を視聴者ごとの関心予測で順位付けする。主な要因は、視聴者の反応（視聴時間、最後まで見る、スキップ、いいね、シェア、コメントなど）、投稿の情報（音源、ハッシュタグ、再生数、投稿国など）、視聴者の情報（言語・地域・端末など）。多くの視聴者では反応が比較的重い。2020年の公式説明では、投稿者のフォロワー数と過去のヒットは直接の要因ではないとしている。新規でもおすすめに載る可能性がある一方、初回配信の人数、拡張条件、各信号の重みは参照した資料では確認できない。公式は、反応が数日続く場合もあると説明している。 [TikTok Help「おすすめの仕組み」](https://support.tiktok.com/en/using-tiktok/exploring-videos/how-tiktok-recommends-content)／[TikTok Newsroom「For You」](https://newsroom.tiktok.com/how-tiktok-recommends-videos-foryou?lang=en-AU)／[TikTok Newsroom「クリエイター向けヒント」](https://newsroom.tiktok.com/5-tips-for-tiktok-creators/?lang=en)

| 指標 | 公式説明で確認できる扱い |
| --- | --- |
| 完了率 | 最後まで見る行動は明示。2020年の説明は、長めの動画を完了する行動を強い関心の例に挙げる。投稿の完了率に一律の合格ラインがあるという公開根拠は確認できない。 |
| リピート再生 | 2020年の説明は、再視聴を視聴者の好みを学ぶ行動の例に挙げる。自動ループと意図的な再視聴の差、投稿配信に対する独立の重みは確認できない。 |
| 保存 | 参照したFor Youの公式説明では、保存の独立した扱いや重みは確認できない。実務上は後から見返したい内容かを判断する参考にする。 |
| シェア | For Youの反応例に明記。完了・保存などとの相対的な重みは確認できない。 |

[For Youの公式説明（現行Help）](https://support.tiktok.com/en/using-tiktok/exploring-videos/how-tiktok-recommends-content)／[2020年の公式説明](https://newsroom.tiktok.com/how-tiktok-recommends-videos-foryou?lang=en-AU)

TikTokの広告ガイドは最初の3秒で価値を提示するよう勧め、広告の尺の目安に21〜34秒を挙げる。問い合わせ自動化に近いGoodcallの広告素材は15〜30秒だった。日本の新規BtoB SaaSアカウントの自然投稿に共通する最適尺は、今回の資料では確認できなかった。 [TikTok for Business「小規模事業向け動画広告ガイド」](https://ads.tiktok.com/business/en/guides/video-advertising-guide)／[Goodcall導入事例](https://ads.tiktok.com/business/en-US/inspiration/goodcall-drives-signups-with-spark-ads)

### 検証案

- **0.0秒**に短い問いと問い合わせカードを表示。**0.5〜1.0秒**で最初の柔らかいクリックとカードの着地、**2.0秒以内**に「何が整理されるか」を見せる。例は「その料金質問、また来た。」と同じ件名のカードが重なる動き。ロゴはUI内に小さく置く。
- 1つの操作なら **12〜18秒**、根拠や引き継ぎまで見せるなら **20〜26秒**、仕様書の3ステップを通すなら **28〜32秒**から試す。同テーマの短尺・長尺で、完了率に加えて平均視聴秒数と業務に関する反応を比べる。
- 課題が分かる最初のフレームと、続きを見たくなる小さな変化を作る。最初の2秒で落ちる場合は冒頭の文言か動きのどちらか一方を変える。24時間だけで判定せず、7日後も集計する。

## 3. 音の設計

### 確認できたこと

TikTokのCreative Codesは音楽・効果音・ナレーションを広告の表現手段として扱い、編集や動きで注意を保つ方法を紹介している。ASMRの調査では明瞭な小音やゆっくりした動きがよく挙がり、別の調査では低めの音や細部に注意を向ける刺激が報告された。Poerioらの実験では、ASMRを経験する参加者で心拍低下と皮膚電気活動の増加が見られた。対象はASMRの知覚・生理反応で、TikTokでの完了率やクリック音・特定BPMの優位性は検証していない。 [TikTok Creative Codes](https://ads.tiktok.com/business/en-US/creative-codes)／[Barratt & Davis, 2015](https://doi.org/10.7717/peerj.851)／[Barratt et al., 2017](https://e-space.mmu.ac.uk/619281/1/Barratt%20et%20al%202017.pdf)／[Poerio et al., 2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC6010208/)

### 制作案

| 音 | 無料の自作方法と使いどころ |
| --- | --- |
| クリック | ローパスをかけた短いノイズ＋小さな低中域の胴鳴り。40〜70ms程度で減衰させ、カードの着地・選択に使う。鋭い先端は数msの立ち上がりで丸める。 |
| タイピング | クリックの音程・強さをわずかに変えた3〜4粒。入力の要点だけ鳴らし、文字が読める状態で音も止める。 |
| ポップ | 正弦波を短く下げながら減衰させる（例 320→160Hz、約100ms）。承認や並べ替え完了に使い、要確認は乾いた1打で区別。 |
| 低音のビート | 正弦波＋控えめな倍音。中低域にも成分を残してスマホの小型スピーカーでリズムを追えるようにする。120 BPMのグリッドを使い、キックは1秒に1回程度のハーフタイム感。音楽なしの効果音版とも比較する。 |
| 音の間 | 資料の矛盾を見せる箇所でBGMと効果音を0.5秒抜く。理由を読む時間を作り、人への引き継ぎで静かに復帰。 |

- 音が先導し、映像の状態が拍で確定する。0.5秒の拍の200〜300ms前に通常の移動を始め、着地フレームと音の立ち上がりを重ねる。場面転換は400〜600msを目安に、2秒ごとの小節頭で収束させる。読ませる場面は画を止める。仕様書のモーション設定に合わせる。
- 合成は無料のローカルツール（Audacity、またはWeb Audioのオフラインレンダリング）で波形・ノイズを作る。効果音の瞬間だけBGMを少し下げ、高域の刺さりや低音の割れをスマホのスピーカー・イヤホンの両方で確認する。スマホでモノラル相当でも主要音を判別できるようにし、ピークには余裕を残す。
- ループの境界では、末尾と冒頭で波形と音量が急変しないようにする。BGMの1小節分の位相をそろえ、残響を収め、ファイルを2回連結して境界を試聴する。投稿プレビューでも確認する。

### 商用音源と素材条件

TikTokは、ブランド・商品・サービスの宣伝には商用利用が事前許諾されたCommercial Music Library（CML）の楽曲を推奨している。一般ライブラリの楽曲に対するTikTokのライセンスは商用投稿をカバーせず、CML外の音は必要な権利を得ていることを確認する。CMLを使う企画では対象地域・掲載先の条件を曲ごとに確認する。今回の音は自作合成を基本にし、外部素材を入れる場合は配布元の個別ページでCC0を確認し、配布URL・作者表示・取得日を記録する。Creative Centerのトレンドは、音源そのものを取り込まず、リズムや演出の調査に使う。 [TikTok Help「商用での音楽利用」](https://support.tiktok.com/en/business-and-creator/creator-and-business-accounts/commercial-use-of-music-on-tiktok?lang=en)／[Creative Center「Commercial Music Library」](https://ads.tiktok.com/business/creativecenter/music/pc/en?rid=motdb9mfpl)／[Creative Commons「CC0 1.0」](https://creativecommons.org/publicdomain/zero/1.0/)

## 4. 文字・セーフゾーン・無音視聴

**確認できたこと。** Ads HelpのIn-Feed用セーフゾーンは画角、投稿文の長さ、追加フォーマットで変わり、端末でプレビューとの差もあり得る。パフォーマンス広告のテキスト目安は毎秒5〜10語。日本語の文字数には直接換算せず、以下は日本語のUI動画用に試す値。 [TikTok Ads Help「In-Feed Ads」](https://ads.tiktok.com/resources/help/article/tiktok-auction-in-feed-ads)／[TikTok Ads Help「Performance Ads」](https://ads.tiktok.com/resources/help/article/creative-best-practices?aadvid=7538083277907935249)

**制作案。** 1080×1920で重要要素を **x=120〜960、y=240〜1260** に入れる。上240／下660／左右120pxは仕様書で採用する保守的な制作余白。視線が右の操作ボタンや下の投稿文に隠れないか、実際の投稿文を入れて端末で確認する。

- 冒頭見出し72〜88px・太さ800以上、説明48〜56px、意味のあるUIラベル40〜48pxを出発点にする。画面全体の録画を縮める代わりに、該当するカードと根拠箇所を寄りで撮る。トークンに沿って明暗差を取り、状態は色と「承認済み」「要確認」の文字で示す。
- 見出しは1画面1メッセージ・最大2行。日本語はまず毎秒5〜7字程度で試す（12〜14字なら約2〜3秒）。0.0秒に出した短いフックは2.0秒以降も読み終わるまで残してよい。数字や根拠が2つある画面は3秒以上を確保し、長文は分割する。
- 無音でも「何の質問か」「なぜ要確認か」「何を改善するか」が画面で伝わるようにする。クリックは押下の見た目、完了音は状態ラベル、無音の間は資料の矛盾箇所で対応させる。後から話し声を入れる場合は字幕を付け、固有名詞と数字を校正する。架空データの表示も読める位置に固定する。

## 5. 投稿運用と最初の10本

**確認できたこと。** TikTokのOrganic Playbookは週2〜3本を例示する。根拠は2021年の内部データと選定アカウントの観察。TikTokは `#FYP` を付けるだけでFor Youに載りやすくなるとはしておらず、投稿内容に関連するタグを勧めている。 [TikTok Organic Playbook](https://ads.tiktok.com/business/library/Organic_Playbook.pdf)／[TikTok Newsroom「クリエイター向けヒント」](https://newsroom.tiktok.com/5-tips-for-tiktok-creators/?lang=en)

**運用案。** 週2〜3本で4週間（3・2・3・2本）。初週は火・木・土の昼を仮の起点に固定し、反応が見えるまで時間帯の差を結論にしない。#1と#8で同じ題材の尺、#4と#9で同じ編集のBGM有無を探索する。オーガニック投稿では配信先や投稿日の差が残るため、各比較の結果は方向性として扱う。

**投稿文例**

> ユーザー追加の料金、同じ質問が何度も来るなら。問い合わせの束から料金ページの追記候補ができるまで。TaskNestはデモ用の架空データです。 #問い合わせ対応 #カスタマーサポート #FAQ改善

投稿文の冒頭に「問い合わせ対応」「FAQ改善」など担当者の言葉を自然に入れる。タグは関連度の高い2〜4個を試す。シリーズ名を付けるなら `#AnswerLoop` を1枠に。CTAは文末の1つに絞り、例は「チームでFAQを見直すときの参考に」や「よく来る質問は料金と仕様のどちらですか？」。概要・デモへの誘導はプロフィールのリンク欄が使えることと遷移先を確認してから入れる。自社の製品を宣伝する投稿ではTikTokのコンテンツ開示設定をオンにし、自社ブランドを選択する。TikTokは開示設定自体が配信に影響しないと説明している。 [TikTok Help「ブランド・商品・サービスの宣伝」](https://support.tiktok.com/en/business-and-creator/creator-and-business-accounts/promoting-a-brand-product-or-service?lang=en)

| 測ること | 記録と判断 |
| --- | --- |
| 初速・到達 | 投稿後24時間と7日で再生数、視聴者数、For You・検索など流入内訳を取得できる範囲で記録。初速の集計時点を統一する。 |
| 冒頭・完了 | 投稿別の維持率曲線で1秒・2秒、最初の操作、要確認、末尾を確認。平均視聴秒数、平均視聴秒数÷尺、完了率を併記する。曲線・完了率が表示されない場合は欠測扱い。 |
| ループ | 再視聴の指標が表示される場合は記録。平均視聴時間÷尺や再生数÷ユニーク視聴者（両方取得できる場合）は補助値とし、意図的なリピート率に換算しない。 |
| 実用性 | 保存・シェア・コメントの件数と、取得できれば各件数÷再生数。母数も添え、嗜好の反応と「承認」「根拠」「FAQ更新」など業務の具体的な質問を読み分ける。 |
| 事業反応 | フォロー、プロフィール閲覧、リンク遷移、デモ希望を取得可能な範囲で記録。投稿単位で帰属できない値はアカウント単位として扱う。 |

TikTok公式の自然投稿向け解説には平均視聴時間や流入情報がある。Ads Managerの「100%再生」にはリプレイが入らず、平均再生時間には含まれるという広告側の定義がある。自然投稿はTikTok Studioに表示される指標名と定義で集計する。 [TikTok Newsroom「TikTok Analytics」](https://newsroom.tiktok.com/product-tutorial-tiktok-analytics?lang=en)／[TikTok Ads Help「Video play metrics」](https://ads.tiktok.com/resources/help/article/video-play?lang=en-302)

## 6. 30.0秒縦動画のキューシート（制作案）

時刻は **0.0秒から0.1秒単位**で記載したイベント頭。30fpsで各0.1秒は3フレーム、30.0秒は書き出しの終点。120 BPM、4/4（1拍0.5秒、1小節2.0秒、全15小節）。9:16、ナレーションなし。全編に「デモ用の架空データ」を小さく表示し、効果音を前、BGMを後ろに置く。移動の着地が記載時刻になるように前段で動きを始める。
