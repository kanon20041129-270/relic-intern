# 当日のインプット（2026-11-28）

## A. SNSマーケティング講座（Relic、PDF 14ページ）の要点
- 目的：作るだけでなく伸ばす。TikTokで実際に投稿し、視聴回数とサービスへの流入を確認する。
- TikTokを選ぶ理由：フォロワー数に関わらず「おすすめ」に出やすい。
- 実績例：社員の個人開発アプリ「Future」。過去投稿が後から伸び続け、インプレッション1万超・DLが右肩上がり。AIで作った簡単な動画でも約600再生。「毎日クオリティを出さなくても600リーチは可能」。過去インターンでは1時間で企画〜投稿し799再生。
- 作り方：CapCut（簡易）、Canva（凝る場合）。参考動画は13〜18秒程度。
- 4つの原則
  1. 再生数が伸びている近い投稿を探して真似する（その領域で何がバズるかを体に染み込ませる）。
  2. 毎日投稿できる仕組み：「文言を変えるだけでフォーマットは一緒」。
  3. 最後にプロダクトの宣伝を入れる（インフルエンサーではなく、プロダクトを伸ばす手段）。
  4. まず無料で需要を見る（56万インプレッションを広告で得るには約20万円）。
- 誘導：アプリ審査やリンク設置は難しいので、QRコード（qr.quel.jp）か、Instagramプロフィールのリンクを使う。
- 手順：①自分のプロダクトの内容でTikTok検索し参考投稿を探す ②CapCutで作る ③投稿。

## B. 現場社員のFB（同じ領域のプロダクトを手がける方）
- プロトタイプを作る意識で。需要は「絶対ある」。
- 差別化の核は応答速度。送信後に待たされるのが今のAIチャットボットの弱点。待たずに3行の答えが出るのが理想。差を作れれば大企業もすぐ入れる。
- 窓口は電話・フォーム・チャットなど複数。電話でもその場で答える音声AIが欲しい。AIだけで完結できたら相当すごい。
- 大企業寄りに売ると価格の桁が変わる。大企業は保守費が高く、意外と内製していない。エンジンは他社と組む手もある。
- 競合：Tayori（AIあり、機能は多いが応答が遅い。AIで解決できないときの流れあり）。価格の参考に。
- 次のライブコーディング講座での見せ方が大事。
